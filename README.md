# AI Workplace Assistant

## Project Overview
AI Workplace Assistant is a practical web-based productivity tool designed to support common workplace activities. It provides guided templates for email generation, meeting summarization, task planning, research assistance, and workplace chatbot interaction.

## Features
- Email generation
- Meeting summarization
- Task planning
- Research assistance
- Workplace chatbot interface
- Copy-to-clipboard response
- Responsible AI guidance
- Responsive design for mobile and desktop

## Technologies
- HTML5
- CSS3
- JavaScript

## Prompt Engineering Examples
1. "Write a professional email requesting a meeting about a project."
2. "Summarize these meeting notes into key decisions and action items."
3. "Turn these tasks into a prioritized work plan."
4. "Create a research plan for the topic and suggest reliable sources to investigate."

## Responsible and Ethical AI Use
AI output should be reviewed by a person before being used at work. Users should not enter confidential or sensitive information into AI systems. Important facts should be checked against reliable sources, and AI should support human decision-making rather than replace appropriate human judgment.

## How to Use
Open `index.html` in a web browser. Select a feature, enter a workplace request, and press Generate.
